# Coach page mockups

Design history for the 1.3.0 coach page. They are static HTML sketches made in a design tool, not part of the plugin. Their inline-styled layout opens in a browser; the design tool's own script is not included.

| File | What it shows |
|---|---|
| Page.dc.html | The first layout of the Overview tab: period buttons, stat tiles, the spend graph, By activity, Projects and MCP servers. |
| PageMM.dc.html | The restyled page the coach now draws: system fonts, the colours, stat tiles in a row, the spend graph beside what is running and the tips. `coach/build_site.py` takes its colours from here. |

All names and numbers in them are sample data. The data the Overview reads is described in [docs/LIVE-FEED.md](../LIVE-FEED.md).
